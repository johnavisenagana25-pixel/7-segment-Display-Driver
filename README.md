# 🚀 7-Segment Display Driver using Verilog HDL

## 🎯 Objective

This project implements a 7-Segment Display Driver using Verilog HDL to display decimal digits from 0 to 9.

---

## 🛠️ Tools Used

* ✅ Verilog HDL
* ✅ EDA Playground
* ✅ Icarus Verilog
* ✅ EPWave

---

## 📖 Project Description

The 7-Segment Display Driver converts 4-bit binary input values into segment control signals required to display decimal numbers.

The project demonstrates:

* ✔️ Combinational logic design
* ✔️ Case statement implementation
* ✔️ Digital display systems
